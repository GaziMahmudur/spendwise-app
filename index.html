📖 Import Guide

1
Export a Full Backup

Go to the Export tab and click "Full Backup (.spendwise)" to create a complete backup of all your data.

2
Save to Safe Location

Store the backup file in Google Drive, cloud storage, or email it to yourself for safekeeping.

3
Import on New Device

After reinstalling, go to Import tab, select your backup file, choose "Full Replace" and click Import.

4
Use Smart Merge

For merging data from multiple devices without losing anything, use "Smart Merge" mode.

What gets backed up?

  • ✅ All expense transactions (full history)
  • ✅ All balance records
  • ✅ All custom categories (with icons & colors)
  • ✅ Currency settings
  • ✅ Metadata (backup date, app version)
